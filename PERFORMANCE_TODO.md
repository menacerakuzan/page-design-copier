# Оптимизация главной — что сделать

Три самые тяжёлые вещи на новой главной (`src/v2`), по убыванию влияния.
Записано 2026-11-05, пока не исправлено.

## 1. Видео в шапке весит 43 МБ

**Где:** `src/assets/episode-01.mp4`, подключается в `src/v2/home/hero/Hero.tsx`.

**В чём проблема.** Файл весит 43 МБ при низком разрешении (1712×748). На мобильном
интернете страница грузится очень долго, тратит трафик, слабые телефоны греются.
Это больше, чем всё остальное на главной вместе.

**Что сделать.**
- Пережать видео: H.264/H.265 или WebM, ~1080p, 2–5 МБ (короткий цикл + сильнее сжатие).
  Либо сразу заменить новым видео нормального качества — владелец всё равно хотел его поменять.
- Отдельная лёгкая версия для телефонов (вертикальная/меньшего размера) через `<source media=…>`.
- Картинка-заставка (`poster`), пока видео грузится; `preload="metadata"`.
- На медленном интернете или при «экономии трафика» (`navigator.connection.saveData`) показывать
  только заставку, без видео.

## 2. Цветокоррекция видео фильтром в браузере

**Где:** `src/v2/home/hero/Hero.tsx`, константа `GRADE`
(`saturate(1.22) contrast(1.06) brightness(1.04) sepia(0.08)`), применяется как `style.filter` к `<video>`.

**В чём проблема.** Фильтр считается видеокартой на каждом кадре видео, всё время,
пока шапка на экране. На слабых устройствах это нагрузка и лишний расход батареи.

**Что сделать.** «Запечь» эту цветокоррекцию прямо в видеофайл при пережатии (пункт 1),
а фильтр из кода убрать. Затемнение поверх видео (градиент) можно оставить — оно дешёвое.

## 3. Главная загружает всю базу целиком

**Где:** хук `useHierarchySnapshot` → `loadHierarchySnapshot()` в `src/lib/adminRepository.ts`.
На главной его используют карта районов, афиша, маршруты, поиск и «Види туризму».

**В чём проблема.** Чтобы показать несколько блоков, главная одним запросом тянет **все**
регионы, районы, города, **все** туристические объекты (с полными описаниями, репертуарами,
контактами) и **все** карточки контента. Сейчас база небольшая и это терпимо, но с ростом
количества мест главная будет открываться всё медленнее (больше данных по сети и дольше
разбор в браузере, особенно на телефонах).

**Что сделать.** Отдельные лёгкие запросы под нужды главной, только с нужными полями:
- карта районов — количество мест по районам и координаты (без описаний);
- афиша — только события с репертуаром на ближайшие 7 дней;
- маршруты — названия, фото и координаты остановок только для показанных маршрутов;
- поиск — подгружать индекс по требованию, когда пользователь открыл поиск.

Полный снимок оставить для админки.
